# Проверки интеграции VL Account × Simla.com

Запуск:

```bash
php tests/run.php
```

WordPress и WooCommerce не нужны: `bootstrap.php` подменяет функции WordPress и
классы плагина Simla заглушками, а клиент API отдаёт заранее подготовленные ответы CRM.
Проверяется логика связки, а не сеть.

| Файл | Что проверяет |
|---|---|
| `test.php` | Определение доступности CRM, разбор ответов программы лояльности (активное/неактивное участие, ошибки, история, сгорание), выбор источника баланса, состояние раздела «Бонусы», фильтрацию служебных купонов, подготовку данных покупателя (телефон, подписка, технический e-mail), приоритет обработки заказа, вступление в программу |
| `test-cart.php` | Расчёт максимума к списанию, ограничение балансом, уровень со скидкой, устойчивость к ошибке CRM, пустая корзина, снятие ограничения купона по техническому адресу |
| `test-gate.php` | Режимы гейта «вход перед покупкой»: какие кнопки перехватываются, тексты, серверный запрет гостевого оформления |
| `test-carts.php` | Снимок корзины гостя и покупателя, контакты, конверсия в заказ, очистка пустой корзины, выдача ключа до отправки заголовков; значения `autocomplete`, поля оформления и подстановка данных аккаунта |
| `test-wishsuite.php` | Объединение списков избранного, режимы источника, двусторонняя синхронизация, перенос избранного гостя, кнопка-сердечко, разбор списка атрибутов |
| `test-subscriptions.php` | Поиск подписок на поступление по ID и по e-mail, размер и статус, фильтры статусов, проверка владельца, отписка |
| `test-address.php` | Поля адреса оплаты и доставки: состав по стране, подстановка из профиля и последнего заказа, адрес одной строкой, проверка обязательных полей и индекса, сохранение, рендер формы |
| `test-name.php` | Поле «Имя» в форме входа: что считается именем (телефон — нет), запись только при отсутствии имени, отображаемое имя вместо номера, создание аккаунта с именем |
| `test-loyalty-auto.php` | Автоматическое вступление в программу лояльности при регистрации: очередь, полный цикл «регистрация → активация», случай уже активного участия, требование кода от CRM, ошибки API, защита от повторов |
| `test-identity.php` | Поиск старого аккаунта по заказам (в том числе по «кривой» записи номера), запрет на аккаунты с правами, подмена пустышки старым аккаунтом, перенос заказов/избранного/промокодов/баллов/профиля/согласий при слиянии, конфликты, выключатели |
| `test-crm-directory.php` | Разбор клиента CRM, связывание по externalId и почте, конфликты на одном телефоне, поиск по номеру в снимке и запросом в CRM, постраничная выгрузка и остановка при ошибке |
| `test-crm-duplicates.php` | Дубли карточек в CRM: какая карточка свежее, склейка недостающих данных, выбор карточки для аккаунта, распознавание номера, за которым стоят разные люди, отбрасывание счёта лояльности без номера, выбор счёта с настоящим балансом вместо приветственного, удаление карточек номера из снимка, передача карточки выжившему аккаунту после слияния |
| `test-sms.php` | Запрос к SMS.RU: имя отправителя в каждом запросе, тестовый режим, разбор кода 204, список согласованных имён и его кэш, сверка настройки со списком (регистр, пробелы, кириллические буквы-двойники) |
| `test-icons.php` | Набор иконок: контур вместо заливки, корректность SVG, толщина линии и фильтр `vlacc_icon_stroke`, разрешения kses |
| `test-templates.php` | Рендер `templates/account/bonus.php` во всех состояниях и `templates/parts/loyalty-cart.php` в трёх режимах |

Тесты лежат вне папки плагина: в поставку `vl-account` они не попадают.

Отдельно полезно прогонять синтаксис всех файлов плагина:

```bash
find vl-account -name '*.php' -exec php -l {} \; | grep -v 'No syntax errors'
```
