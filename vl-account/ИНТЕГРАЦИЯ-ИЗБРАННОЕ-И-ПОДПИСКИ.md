# VL Account × WishSuite × Back In Stock Notifier

Документ описывает связку личного кабинета с двумя плагинами:

* **WishSuite** — избранное (сердечки у товаров);
* **Back In Stock Notifier for WooCommerce** (`cwginstocknotifier`) — подписка на
  поступление отсутствующего размера.

Оба плагина **не изменяются**: логика связки лежит в
`vl-account/includes/integrations/` и работает через их публичные классы и
стандартные хуки WordPress. Выключите любой из них — кабинет продолжит работать.

---

## 1. Избранное WishSuite в кабинете

### Что было

WishSuite хранит избранное в своей таблице `{prefix}wishsuite_list`, а кабинет —
в метаполе пользователя. Это два независимых списка: товар, добавленный сердечком
WishSuite, в разделе «Избранное» кабинета не появлялся.

### Что стало

| Что | Как работает |
|---|---|
| Раздел «Избранное» | Показывает список WishSuite и собственный список кабинета как один, без дублей |
| Счётчик `[vl_wishlist_count]` | Считает объединённый список и обновляется сразу после клика по сердечку WishSuite |
| Кнопка «убрать» в кабинете | Убирает товар и из WishSuite — сердечко у товара гаснет |
| Избранное гостя | Переносится в аккаунт при входе. Сам WishSuite этого не делает: список гостя живёт в куке и во временных записях, и после входа товары «пропадали» |
| Две кнопки-сердечка | Пока WishSuite активен, собственная кнопка кабинета в карточке товара не выводится |
| Выгрузка в RetailCRM | Избранное уходит в CRM уже с учётом списка WishSuite (поле указывается в настройках Simla) |

### Настройки

**Личный кабинет → Личный кабинет → Избранное и плагин WishSuite**:

| Настройка | По умолчанию | Смысл |
|---|---|---|
| Показывать избранное WishSuite | вкл | Общий выключатель связки |
| Какой список показывать | оба вместе | оба / только WishSuite / только кабинет |
| Возвращать изменения в WishSuite | вкл | Двусторонняя синхронизация |
| Переносить избранное гостя | вкл | При входе список гостя уезжает в аккаунт |
| Не дублировать сердечко | вкл | Прячет собственную кнопку кабинета |

Там же — таблица проверок: активен ли WishSuite, есть ли его таблица, сколько
товаров в каждом из списков у текущего пользователя.

## 2. Размеры кнопками

Выпадающий список размеров заменяется кнопками **в карточке товара** и **в быстрой
корзине избранного WishSuite**. Раньше это делали два разных скрипта в шаблонах —
их можно удалить.

Что делает плагин лучше самописных скриптов:

* **Недоступные размеры видны, но неактивны.** WooCommerce выкидывает из списка
  размеры, которых нет в наличии; плагин запоминает полный набор и показывает
  отсутствующие перечёркнутыми — покупателю видно, что размер существует, но его нет.
* **Работает с формой, приехавшей по AJAX** (быстрая корзина WishSuite) и
  перерисовывается, когда WooCommerce пересчитывает доступные варианты.
* **Не задваивает кнопки.** Если контейнер `.size-buttons` уже создал шаблон темы,
  плагин забирает его себе, а лишние убирает.
* **Классы сохранены** — `.size-buttons` и `.size-button` с модификатором `.active`,
  так что уже написанный в теме CSS продолжает работать. Дополнительно есть
  `.vl-size-buttons` / `.vl-size-button` и состояние `.is-disabled`.

### Настройки

**Личный кабинет → Личный кабинет → Размеры кнопками**:

| Настройка | По умолчанию | Смысл |
|---|---|---|
| Включить кнопки размеров | вкл | Работает и без WishSuite |
| Где выводить | везде | Везде / только в быстрой корзине WishSuite |
| Атрибуты для кнопок | `pa_razmer` | Коды атрибутов через запятую; пусто — все атрибуты. Список кодов магазина подсказан прямо в поле |

### Заодно починено

WishSuite в обработчике клика по сердечку вызывает счётчик Яндекс.Метрики
`ym(...)` без проверки. Если Метрика не загрузилась (блокировщик рекламы, ошибка
сети), обработчик падал с ошибкой **до** отправки запроса — товар не добавлялся
в избранное. Плагин объявляет безопасную заглушку `window.ym`, если её нет.

## 3. Подписка на поступление размера

### Что было

Покупатель подписывался на отсутствующий размер, но раздел «Подписки» в кабинете
оставался пустым: он ждал данные через фильтр, а источник не был подключён.

### Что стало

Раздел «Подписки» показывает товар, размер, дату и статус подписки, а также даёт
отписаться в один клик.

Как читаются подписки: плагин `cwginstocknotifier` хранит их записями типа
`cwginstocknotifier` (заголовок — e-mail подписчика, товар и вариация — в метаполях).
Кабинет ищет их **и по ID пользователя, и по его почте** — подписаться можно было
до регистрации или из другого браузера, такие подписки тоже попадут в кабинет.

Статусы:

| Статус плагина | Как показываем |
|---|---|
| `cwg_subscribed` | ждём поступления |
| `cwg_mailsent` | уведомление отправлено |
| `cwg_mailnotsent` | уведомление не доставлено |
| товар снова в наличии | «снова в наличии» зелёным |

Кнопка «отписаться» переводит подписку в статус `cwg_unsubscribed` — тем же
методом, что и админка плагина, так что его собственная логика не нарушается.

### Настройки

**Личный кабинет → Личный кабинет → Подписка на поступление размера**:

| Настройка | По умолчанию | Смысл |
|---|---|---|
| Показывать подписки в кабинете | вкл | Общий выключатель |
| Показывать отработавшие подписки | вкл | Те, по которым письмо уже ушло |
| Искать подписки по e-mail | вкл | Подхватывает подписки, оформленные без входа |

Выше настроек — таблица проверок: найден ли плагин, сколько подписок по магазину
и сколько нашлось у текущего пользователя.

## 4. Если подписки всё равно не видно

1. **Личный кабинет → Диагностика** — строка «Подписки текущего пользователя»
   покажет, сколько записей нашлось именно для вас.
2. Если там ноль, а в **Товары → Back In Stock** подписка есть — сравните e-mail
   подписки с почтой аккаунта. При входе по SMS без почты у аккаунта технический
   адрес вида `79001234567@phone.сайт`, а подписка оформлена на настоящий.
   Подтвердите настоящую почту в кабинете («Мои данные» → e-mail) — после
   подтверждения подписки подтянутся.
3. Если статус подписки `Unsubscribed` или `Mail Sent`, а показывать её нужно —
   включите «Показывать отработавшие подписки».

## 5. Точки расширения

| Хук | Тип | Назначение |
|---|---|---|
| `vlacc_wishlist_items` | фильтр | Итоговый список избранного: `($items, $user_id)` |
| `vlacc_wishlist_updated` | действие | Товар добавлен или убран: `($product_id, $state, $user_id)` |
| `vlacc_wishlist_merged` | действие | Избранное гостя перенесено: `($user_id, $guest_items)` |
| `vlacc_user_subscriptions` | фильтр | Список подписок: `($items, $user_id)` |
| `vlacc_stock_notifier_statuses` | фильтр | Какие статусы подписок показывать |
